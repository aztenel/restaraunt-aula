# Сценарий видеоуроков по админ-панели AULA

Серия коротких видео (3–7 минут) по ролям сотрудников. Видео дополняют
[инструкцию для администратора и персонала](admin-guide.md): в конце каждого ролика — ссылка на её раздел.
Всё, что показывается, есть в текущей версии админки; названия кнопок в закадровом тексте совпадают с экраном.

## 2. Технические требования к съёмке

- **Запись:** 1920×1080, 30 кадров/с, MP4 (H.264), звук 48 кГц. Запись окна браузера Chrome, окно 1600×900,
  масштаб страницы 110% — текст читается на телефоне. Подсветка курсора и щелчков включена.
- **Интерфейс:** язык админки — русский (переключатель в шапке). Казахская версия — субтитры (или отдельная
  озвучка по тому же сценарию, с переключением интерфейса на «Қазақша»).
- **Звук уведомлений:** в роликах 00 и 01 звук новых заказов должен быть слышен — записывайте системный звук.
- **Озвучка:** спокойный темп, около 120–130 слов в минуту; текст — из колонки «Закадровый текст». Паузы между
  сценами — 0,5–1 с. Закадровый текст можно слегка сокращать под монтаж, но не менять названия кнопок.
- **Структура каждого ролика:** заставка с названием (3 с) → «Что вы узнаете» (10 с) → сцены → итог (10 с) →
  финальная плашка «Подробнее: инструкция, раздел N» (3 с).
- **Монтаж:** долгие ожидания (расчёт, загрузка) вырезать; на важных кнопках — увеличение 1,5× на 1–2 с; подписи
  к ключевым правилам — плашкой внизу экрана (текст плашки указан в сценах как «Плашка»).
- **Данные:** только демо-данные staging. Реальные телефоны, email и ключи интеграций в кадр не попадают: в ролике 12
  поля секретов показываются пустыми (как в админке) или заполняются заведомо тестовыми значениями.
- **Файлы:** `AULA-admin-<№>-<латиница>.mp4`, например `AULA-admin-01-orders.mp4`; субтитры —
  `AULA-admin-01-orders.ru.srt`, `...kk.srt`.

## 3. Подготовка стенда и демо-данных

### 3.1 Стенд

Съёмка — на staging (или локальном стенде) с демо-данными. Сид запускается один раз:

```bash
SEED_DEMO=true \
SEED_OWNER_EMAIL=owner@aula.kz SEED_OWNER_PASSWORD='<пароль для съёмки>' \
SEED_ADMIN_EMAIL=admin@aula.kz SEED_ADMIN_PASSWORD='<пароль для съёмки>' \
pnpm --filter @aula/api seed
```

На staging — командой из [operations.md](operations.md) (раздел «Стартовые и демо-данные»). Без
`SEED_*_PASSWORD` сид выведет временные пароли, и при первом входе потребуется смена пароля.

Вне production онлайн-оплата идёт через **тестовый платёжный провайдер (песочницу)**: страница оплаты с кнопками
«Оплатить» и «Отказ». Неподключённые каналы уведомлений пишут сообщения в журнал приложения — ссылки на оплату
и смету берите из карточек в админке.

## 4. Порядок съёмки

Порядок публикации — по номерам. Порядок съёмки учитывает зависимости данных:

1. **11** — администратор заполняет юрлицо и создаёт сотрудника с временным паролем (он нужен для ролика 00).
2. **00** — первый вход этого сотрудника.
3. **12**, **07**, **08** — настройки и меню.
4. **03** — стоп-лист, цены, зоны, промокод.
5. **01** — заказы (с живым заказом с сайта).
6. **09** — финансы: выпуск сертификатов по счёту (код для ролика 02).
7. **02** — брони и погашение сертификата.
8. **04**, **05**, **06**, **10**.

## 5. Сценарии

Формат сцены: **что на экране** (действия по шагам) и **закадровый текст**. Время — ориентир для монтажа.
